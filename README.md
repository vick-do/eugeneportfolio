# Eugene Gyasi - Portfolio Website

A professional graphic designer portfolio website built with HTML, Tailwind CSS, and JavaScript.

## Features

- **Responsive Design**: Works perfectly on all devices
- **Modern UI**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, smooth scrolling, and dynamic content
- **Polaroid Gallery**: Unique image presentation style
- **Process Section**: Detailed breakdown of design workflow
- **Contact CTA**: Clear call-to-action for potential clients

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # Custom CSS styles
├── script.js           # JavaScript functionality
└── README.md          # This file
```

## Setup Instructions

1. **Add Your Images**: Replace the placeholder image paths with your actual images:
   - `hero-image.jpg` - Hero section background image
   - `portfolio-1.jpg`, `portfolio-2.jpg` - About section images
   - `work-1.jpg`, `work-2.jpg`, `work-3.jpg` - Featured work images

2. **Open in Browser**: Simply open `index.html` in your web browser

3. **Customize Content**: 
   - Update the text content in `index.html`
   - Modify colors in Tailwind classes (search for `[#4a1f1f]` to change brand color)
   - Update social media links

## Technologies Used

- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework (CDN)
- **JavaScript**: Interactive functionality
- **Google Fonts**: Playfair Display & Inter fonts

## Sections

1. **Navigation**: Fixed navbar with menu toggle
2. **Hero Section**: Large header with name and tagline

4. **Featured Work**: Showcase of design projects
5. **Process Section**: 5-step design process breakdown
6. **CTA Section**: Call-to-action for collaboration
